# Repo Hygiene

## Purpose

This note defines the tracked-artifact cleanup rules for the March 2026 readiness baseline.

## Removed Tracked Noise

The readiness cleanup removes tracked artifacts that should stay local-only:

- Python cache directories such as `__pycache__/`
- Compiled Python cache files such as `*.pyc`
- Playwright or other ephemeral `test-results/` outputs
- Failure screenshots and error-context files generated by local test runs

## Prevention Rules

The repo already ignores these artifact families in `.gitignore`:

- `test-results/`
- `playwright-report/`
- `__pycache__/`
- `*.pyc`

## Expectations

1. Do not commit generated caches or local test-result artifacts.
2. If a local debug artifact matters for review, move it into a deliberate evidence or report path instead of keeping it under generated cache folders.
3. If a new tool emits repeat local noise, add the ignore rule before the artifact family is committed again.
